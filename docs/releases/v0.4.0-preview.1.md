> [!WARNING]
> **This is a preview.** It's an early look at what we're building for 0.4.0, published so you
> can try it and tell us what breaks. It has automated tests, but it has barely been used in a
> real game yet. Expect rough edges, and expect the API to change before 0.4.0.

## In short

Agenerela lets a language model decide what your game's characters do, picking only from
actions you've allowed. This preview is about **catching the model's mistakes before your game
acts on them**, and about making agents a little easier to set up.

## What's new

### 🛡️ Bad answers get stopped

Every answer from the model now goes through a row of checks before your character does
anything. If a check isn't happy, the character simply does nothing, and you can see which
check stopped it and why.

- **Asking for something that isn't there.** Tell the guard *"Attack the scarecrow"* when the
  only thing nearby is a training dummy. A small model used to attack the dummy anyway, the
  closest thing it was allowed to name. Now Agenerela notices the model was hesitating over a
  name it couldn't write, and the guard stays put.
- **Half an answer.** "Walk to…" with no destination is refused instead of being run.
- **Made-up actions or targets** are now caught as soon as the model answers, not only at the
  moment you run them.

### 👀 Characters can look around

Until now you had to tell an agent everything it should know. Now it can notice its
surroundings by itself: add a nearby-objects source, and each decision includes a short
description of what's close, nearest first. You can write your own sources too, for whatever
your game knows.

### ⚙️ Choose your model once

Pick the model in one place instead of in every agent's code. Make the settings with
**Create → Agenerela → Ollama Provider**, choose them under **Project Settings → Agenerela**, and
every agent you create with `ProviderConfig.Resolve()` shares them.

### 📄 MIT licence

Agenerela is now open source under the MIT licence. Use it in any game, free or paid; just keep
the licence file with it.

## Not there yet

- **How often it gets things right hasn't been measured.** The accuracy numbers in our docs
  come from the prototype this was built from, not from this release.
- **It only talks to Ollama**, a free app that runs models on your own computer, and it must be
  running. A game you ship would need Ollama on the player's machine too.
- **No editor windows yet.** Agents are still set up in code.
- **When a check stops a character, its words don't change yet.** It can say *"Attacking the
  dummy!"* and then stand still. Fixing that, and letting you add your own checks, is planned
  for 0.4.0.

## Upgrading from 0.3.0

Nothing to change in your code. Two things now behave differently: an action that needs a
target but got none is refused, and an answer naming something that wasn't offered comes back
as "do nothing" right away instead of failing later in `Execute`.
