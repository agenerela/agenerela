Every decision What happens each time a game asks an agent to decide, and which screens show that step
AGame asks

The game's own code calls the agent with free text and observations.

BMenu is built

Only actions legal right now, plus registered targets. none is always added.

CModel chooses

It can only answer inside that menu: action, then target, then statement.

DGuards re-check

Legality and grounding checks. A bad choice becomes none.

EGame code runs

The developer's handler carries it out. The model never touches Unity.

FTelemetry saved

Latency, tokens and guard verdicts, for debugging and measuring.
