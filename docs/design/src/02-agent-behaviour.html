What the numbers point to

1
Profile

Points to the shared Agent Profile from screen 1. Ten guards can use one profile.

2
Model provider

Where the model runs: Ollama while developing, a cloud API or an in-game model later. Shows whether it's connected.

Now (DR-013): a provider config asset. This field is only an optional override; blank means the project default.
3
Actions → game code

Each action is bound to a handler: the developer's own C#. An action with no handler is flagged and never offered to the model.

Now (DR-011): only asset-authored actions are bound here; a code-authored action's method is its own handler.
4
Targets

The scene objects this agent may refer to. The model can only name ids from this list.

Now (DR-014): discovered each decision from nearby Targetable components, not typed per agent.
5
Live menu (Play mode)

Exactly what the model is offered at this moment. Illegal options are left out entirely, not forbidden in the prompt.

6
Try a decision

Type a stimulus, press Decide, and see the action, target, reply and latency, without writing any test code.
