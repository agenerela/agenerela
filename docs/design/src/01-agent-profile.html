What the numbers point to

1
Identity

Name, role, personality and goals. The framework builds the prompt from these fields, so the developer never writes one.

2
Action list

Drag in Action assets. This is everything the agent can ever do; the game's code decides which are legal at any moment.

3
Length check

Each description should be one short clause of similar length. A much longer one biases small models toward it, so it gets flagged.

4
Edit an action in place

Expand a row to set its example stimulus and the targets it makes sense for, with a preview of the example the model will see.

5
Built-in “none”

Added by the framework, always last and locked, so a developer can't forget it or delete it.

6
Problems where you look

An empty name, an empty row or a duplicate id shows up here, with a fix button, not only in the Console.
