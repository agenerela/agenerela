What the letters and numbers point to

A
First open

Until it can run, the window says how to start. One primary button fills steps 1 to 3; what the project lacks shows as a problem box with its fix.

B
A run

Progress per answer, and Cancel. A cancelled run keeps its partial report, marked as no result.

1
Run set-up

Set, profile, two arms with a name and the grounding guard each, the order. Run A/B is greyed with the reason under it. New in #179: folded once a report is shown.

2
Five outcomes, not one score

A bar per arm and each outcome's share, with the difference. Fills come from the kit's variables, so both skins read.

3
Noise check

One sentence, on accuracy: a difference smaller than the floor at this n is no result.

4
By category

Each with its own n and noise check, so the headline is never measured on player chat alone. Ids are the kit's chips.

5
Not correct

Either arm, filtered by outcome. Open expands the whole answer in place, until the Decision Log (#172) can show it.

6
Labels and export

Agreement in the Prompt Set window's own counts, and the export buttons. The same as #146, in the kit's look.
