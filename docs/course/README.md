# Course materials

COMP 490 deliverables that were built as shared web pages rather than documents: each one
collects the team's answers for a Canvas practice and produces the text every member posts.
They are archived here so they outlive the links, and so a reader a year from now can see
what the class asked of us and what we said.

| Date | Page | What it is |
|---|---|---|
| 2026-09-10 | [`2026-09-10-requirements-practice.html`](2026-09-10-requirements-practice.html) | In-class requirements practice: one reply per teammate, each naming the feature that person owns on GitHub, three user requirements, and the system requirements beneath them | 
| 2026-09-10 | [`2026-09-10-interview-kit.html`](2026-09-10-interview-kit.html) | Requirements interviews: the questions each person asks, room to record what they heard, and the requirement changes those answers support |
| 2026-09-10 | [`2026-09-10-interview-replies.html`](2026-09-10-interview-replies.html) | The replies built from those interviews, each change pointing back to a requirement id from the first practice |
| 2026-09-17 | [`2026-09-17-lab-kit.html`](2026-09-17-lab-kit.html) | Sketch/mockup lab: the sitemap and the six screen wireframes, with the text posted alongside each figure |
| 2026-09-24 | [`2026-09-24-system-design.html`](2026-09-24-system-design.html) | System design: the group leader's reply, with our goals and how we reach each, hardware, software, algorithms and user stories, and the framework figure sized for Canvas's Medium image |

Open any of them by double-clicking the file; they are self-contained pages that need no
server. The lab kit and the system-design page load their figures from
[`../design/png/`](../design/png), so keep them in this folder or the images will not resolve.

**These are snapshots of the page, not of the answers.** Anything typed into one of these
pages while it was live is kept by the page itself, not in this file, so a saved copy shows
the questions and the structure with the fields empty. The live versions, which still hold
what people entered:

The three 2026-09-10 pages carry the team roster — six first names and GitHub handles, the
same ones the commit history shows — and the 2026-09-24 page names the same six by first
name. This repository is public; if we would rather these read as "Member 1–6", that is a
small edit to each file.

Design work that came out of these practices — the sitemap, the six wireframes and the
framework figure, with their sources — lives in [`../design/`](../design/README.md), not here.
