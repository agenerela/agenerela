# Living Vale

Standalone Unity **6000.3.23f1**, Universal 3D (URP) project for the
[Living Vale RPG demo](../../docs/demos/living-vale.md), tracked in
[#69](https://github.com/agenerela/agenerela/issues/69).

Open this folder in Unity Hub with the pinned editor. The framework loads from
`UnityProject/Packages/com.agenerela.framework` through a relative local package
reference; game code belongs under `Assets/LivingVale/` in the `LivingVale` assembly.

This is the initial project setup. The template scene is still in
`Assets/Scenes/SampleScene.unity`; movement, NPC chat and other game systems are
not implemented yet. Follow G0 and G1 in the build plan for the first playable slice.
